## Before You Start

- Every workspace reads the shared libraries in [`../libraries/`](../libraries/README.md). Set up your brand there first, or use the demo brand, Acme Coffee Co.
- Start in the workspace's brief stage. No separate intake or planner step.
- Each workspace has an optional `setup/questionnaire.md` for reusable preferences.
- If nothing here fits, build a workspace with the workspace builder.

## Workspaces Versus Libraries

- A workspace makes one kind of deliverable. Its stages hold the job's files.
- A library keeps reusable records, such as brands, saved references, and media. Workspaces read them.
