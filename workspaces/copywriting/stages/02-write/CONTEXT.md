# Stage 02: Write

Write or revise the complete text deliverable from the job's brief.

## Inputs

| Source | Location | Scope | Why |
|---|---|---|---|
| Brief | `../01-brief/output/[slug]/brief.md` | Full | Direction and plan |
| Skill | Selected canonical writing skill | Needed sections | Writing method |
| Sources | Pointers selected in the brief | Relevant sections | Facts, voice, examples |

## Process

1. Follow the brief's angle, audience, voice, length, offer, and CTA.
2. Write the complete copy. Label variants only when requested, keeping common facts consistent.
3. Check every factual claim against the selected sources; mark missing approval or uncertain claims visibly.
4. Keep source notes and editorial comments separate from publishable copy.
5. Audit, save the draft, and continue to review. Preserve user edits and accepted language during revision.

## Audit

| Check | Pass Condition |
|---|---|
| Fit | Copy serves the stated objective, placement, and audience |
| Voice | Brand rules and length constraints respected |
| Truth | Claims sourced or explicitly pending; references not copied verbatim |
| Completion | Full draft exists with unresolved questions visible |

## Outputs

| Artifact | Location | Format |
|---|---|---|
| Copy draft | `output/[slug]/copy.md` | Deliverable text plus separate source/editorial notes |
