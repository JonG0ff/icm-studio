# Copywriting

Produce copy-only deliverables such as captions, posts, emails, and text drafts. Start from the user's request at `stages/01-brief/CONTEXT.md`.

This workspace owns its brief, draft, revisions, and delivery review. It uses selected facts from `../../libraries/business-memory/`, references from `../../libraries/swipes/`, and relevant writing skills under `../../skills/ai-capabilities/sales-marketing/`.

Use `CONTEXT.md` for routing. Setup is optional; see `setup/questionnaire.md`. Existing accepted copy/specs can be brought in without repeating their approvals. Unsupported visual production needs an explicit destination; this workflow delivers text files.

Keep claims sourced, preserve brand voice and rights, and do not paste swiped copy verbatim. Review modes follow Pattern 19 in `../../_core/CONVENTIONS.md`. A final draft never authorizes publishing, sending messages, or changing approved library facts.
