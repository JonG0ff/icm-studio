# Formats

A format is a recipe on top of the fixed production line. New content type = new recipe file. The line doesn't change.

## Live Recipes

| Format | File | Status |
|--------|------|--------|
| Skit short | `skit-short.md` | Live, first format |
| Music visual | `music-visual.md` | Trial |

## Every Recipe Sets

| Field | What it decides |
|-------|-----------------|
| Platform | A row in `../platform-specs.md` |
| Length | Target seconds, min and max |
| Structure | The sections, in order |
| Speakers | Min and max cast on screen |
| Hook rules | How the first seconds work |
| Variants | How many hook variants to write and render |
| Captions | On or off, and the style |
| Ending | How it ends |

## Add a Format

1. Copy `skit-short.md` to `[format-name].md`.
2. Change every field. Delete what doesn't apply.
3. Add a row to Live Recipes.
4. Run one real video with it before calling it live.
