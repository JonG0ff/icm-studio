# Staging Limits

What code animation does well, and the workaround when it doesn't. Script and blocking check against this.

## Easy in Code

- Talking: 6-8 drawn mouth shapes switched by word timing.
- Expression swaps: angry, shocked, smug, dead inside.
- Cheap physical comedy: squash and stretch, shake, bounce, fall off-screen, spin.
- Camera: zooms, whip pans, push-ins, smash cuts.
- Effects: wind, rain, debris, explosions, speed lines, impact frames.
- Broadcast graphics: lower thirds, tickers, score bugs, BREAKING NEWS banners.
- Comedy timing: holds, awkward pauses, freeze frames, record scratches, exact to the frame.

## Hard, and the Workaround

| Hard | Workaround |
|---|---|
| Fluid full-body acting (running, dancing, fights) | Dust-cloud fight, a cutaway, a sound off-screen, a "footage lost" card |
| Hands using objects | A small prop library. Stiff holding is the gag. |
| Turning around, 3D perspective | Front and three-quarter views only. Hard cut between angles. |
| Crowds | Recolored silhouettes, or cardboard cutouts |
| A frame-accurate copy of a viral clip | A deliberately bad re-enactment |

## Rule

- If a script or cue asks for something in the Hard column, use its workaround or cut it.
- Never block an action the character's library entry lists under "Can't do".
