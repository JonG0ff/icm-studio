# Video Production Setup

Setup is optional. This workspace can run from a direct request and its workspace brief without defaults.

Use setup only when the user wants reusable production preferences.

This workspace has no setup tokens. Brand values come from Business Memory setup.

## Questions

1. Default editor or NLE?
   - Examples: Final Cut Pro, Premiere, CapCut, DaVinci Resolve, Remotion.
   - File: `../shared/edit-package-format.md`

2. Default asset sources?
   - Examples: user-shot footage, public archive, stock library, AI generation, screen capture.
   - File: `../shared/asset-manifest-format.md`

3. Default sound approach?
   - Examples: no music, cinematic bed, subtle risers, hard cuts, UI clicks.
   - File: `../shared/edit-package-format.md`

4. Default caption style?
   - Examples: sparse emphasis phrases, full captions, no captions.
   - File: `../shared/edit-package-format.md`

5. Default color style?
   - Examples: dark cinematic, clean bright, documentary neutral.
   - File: `../shared/edit-package-format.md`

Do not store credentials, paid library keys, or account details here.
