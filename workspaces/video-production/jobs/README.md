# Video Job Records

Use `jobs/[slug]/` only when a job needs notes that no stage artifact holds, such as decisions carried in from another tool.

New jobs do not need a card or a separate tracking file. Status comes from the brief, stage artifacts, and approvals.

Read the latest stage output for current state. An older note does not override a newer artifact or grant approval.

Briefs live in [brief output](../stages/00-brief/output/). Scripts and later artifacts stay with their stages. [Publishing and results](../publishing/README.md) owns performance reads, cell ledgers, and the publish queue.
