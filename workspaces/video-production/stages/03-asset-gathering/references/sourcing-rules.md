# Sourcing Rules

The production job describes needs, selects media, and decides placement. The media library owns reusable records, rights, paths, and reuse history. Skills own sourcing procedures; their bundled tools execute searches and downloads.

## Source Priority

1. Check `../../../../../libraries/media/assets/index.md` and matching records first.
2. For a specific real-world person, event, place, or moment, use the media-sourcing YouTube reference tools when appropriate. Keep results `internal-reference-only` unless separately cleared.
3. For named athletes, movie publicity, and news/press stills, use web-still sourcing and record rights as unclear until assessed. For mood/object/place visuals, use Pexels, Wikimedia Commons, or the appropriate stock tool. Choose the applicable branch instead of wasting a generic-stock pass on a named subject.
4. Consider AI generation only when sourced material cannot serve the essential need after editing/cropping/grading. Record why, model, prompt, and cost, then follow the generation skill and approval rules.

A swipe reference or YouTube reference is not a cleared production asset. Carry source and rights notes into the job manifest.

## Candidate Files

- Use the scene plan's media type. Footage-led work needs video; still-first packs need stills.
- Set candidate volume using the selected format and coverage plan. Short-form footage normally needs eight to ten candidates per scene; long form uses chapter/sequence coverage needs.
- Search varied, specific terms from the approved direction. Avoid generic stock that merely matches a keyword.
- Download authorized free-source candidates before review. Record local path and source metadata.
- Organize local files by job and chapter/scene or asset group under `../../../../../libraries/media/local-media/`.
- A numbered, timecoded still-first shot brief uses the still-bank skill. Do not replace its full-bank procedure with individual improvised picks.

## Audio And Generation

- Use audio-rip for temp/cleared extraction and stems; rights still need assessment.
- Use the voiceover skill for voice criteria and tagged script packets. Use the voice-generation skill only when generating approved takes.
- Use sound-effects-mix for SFX sourcing and timing. Fill the selected-download metadata and download actual audio files. Search packets alone do not close SFX needs.
- Queue paid licenses and credit-consuming generation with cost and fallback before execution.
- Follow Pattern 19 and the matching skill's spend rules. Never run paid AI image/video generation without asking.
- Preserve accepted script, hook, shot list, and visual decisions while sourcing. Escalate a real impossibility with a concrete fallback.

## Completion

An asset becomes ready only with a usable source and documented use/rights conditions. Keep blocked, unclear, internal-reference-only, and pending approval states visible. Catalog promotion requires its own library approval.
