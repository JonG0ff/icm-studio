# Edit Notes

Use these notes when creating the edit package.

## NLE

Name the intended editor, such as Final Cut Pro, Premiere, CapCut, DaVinci Resolve, or Remotion.

## MotionVFX

List any template, transition, title, logo, or overlay needs. If the exact template is unknown, describe the effect and mark it as open.

## Sound

Name music bed, silence, risers, impacts, UI clicks, whooshes, ducking, and voiceover mix notes.

## Color

Name contrast, temperature, grain, vignette, black levels, highlight behavior, and brand color use.

## Export

State platform, resolution, frame rate, codec, filename, and loudness target when known.
