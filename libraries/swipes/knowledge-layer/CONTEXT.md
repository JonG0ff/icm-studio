# Knowledge Layer

Curated marketing references. The product of Swipe Engine. Grows across runs. Commit entries to version control.

## Files

| File | Key Sections | Load When |
|------|-------------|-----------|
| `index.md` | Full catalog table | Finding entries by slug, type, or tag |
| `entries/[slug]-reference.md` | Full file | Working with one saved reference |
| `entries/[slug]-reference.md` | "Visual" | Design, layout, color decisions |
| `entries/[slug]-reference.md` | "Copy" | Hooks, offers, CTAs |
| `entries/[slug]-reference.md` | "Video Timeline", "Audio", "Combined Patterns" | Media references, scripts, and motion briefs |
| `entries/[slug]-reference.md` | "Patterns worth reusing" | The destination production workspace's brief and planning stages |
| `assets/[slug]/manifest.json` | Acquired context artifact inventory | Extracting or reopening a curated reference |
| `patterns/visual-patterns.md` | Full file | Cross-reference visual trends |
| `patterns/copy-patterns.md` | Full file | Cross-reference hooks and CTAs |
| `patterns/media-patterns.md` | Full file | Cross-reference audio/visual timing, motion, and spoken CTA patterns |

Nothing enters this folder without human approval at stage 03-curate. Curated entries point to durable context artifacts under `assets/[slug]/`; raw staged video, audio, and PDFs are not promoted.
