# Extraction Fields

Required sections for `output/[slug]-extraction.md`.

```markdown
# Extraction: [title]

- slug: [slug]
- source: (from intake)
- extracted: YYYY-MM-DD

## Visual

- colors: (hex or descriptions)
- typography: (fonts, sizes, weights if visible)
- imagery: (photo, illustration, icon style)
- layout: (structure notes)

## Copy

- hook: (opening line or pattern)
- hook-type: (visual: scroll-stopper | head-scratcher | none observed) + (text: emotion-striking | curiosity-building | withheld-secret | none observed)
- body: (key phrases or structure)
- offer: (promotion, pricing, value prop)
- cta: (call to action text)
- tone: (2-3 adjectives)

## Layout patterns

(bullet list of reusable structural patterns)

## Video Timeline

- scenes: (timestamped scene or beat notes; use "none observed" for non-video)
- frames: (notable sampled frames and what is visible)
- motion: (low/medium/high motion moments or transitions)
- reset cadence: (seconds between visible changes; longest static hold and its timestamp; use "none observed" for non-video)
- on-screen text: (visible/OCR text with timestamps)

## Visual inspection

- inspected artifacts: (contact sheet and representative sampled-frame paths opened with the local image viewer; use "not applicable" for audio-only sources)

## Audio

- transcript hook: (opening spoken line or pattern)
- voice/tone: (delivery style, if audible or transcript-supported)
- music/sound: (music, silence, sound effects, or "none observed")
- spoken CTA: (spoken call to action with timestamp if available)

## Combined Patterns

(bullet list tying visuals and audio together: hook timing, text overlays, cuts, motion peaks, CTA moment)

## Animation style

Only for references tagged `animation-style`. What the image shows, not how to build it. Programmatic animation grades feasibility.

- line: (weight, variation, wobble, color, or no outlines)
- fill and shading: (flat, cel, gradient, painted, hatched)
- texture: (paper, grain, brush, halftone, none)
- palette: (hex where visible, color count)
- construction: (shapes, proportions, how faces and hands are built)
- motion: (puppet, morphing, full redraw, frame rate; "still image" if none)
- camera and depth: (flat, parallax, 3D)
- defining traits: (the 1-3 traits someone would name first)

## Patterns worth reusing

(bullet list -- agent proposal, human confirms at curation)

## Uncertainties

(fields marked uncertain or not visible in source)
```

Mark `(uncertain)` on any field the agent cannot verify from the source.
