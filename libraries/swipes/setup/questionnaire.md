# Swipe Engine Setup Pointer

The swipe engine does not have a required setup questionnaire.

When the user types `setup` here, route them to:

`../../business-memory/setup/questionnaire.md`

Use Business Memory for reusable brand, company, SOP, and approved project details.

Store approved setup answers in Business Memory. Swiped references belong in the reference loop:

`01-save -> 02-extract -> 03-curate`

Deliverable planning belongs in the destination production workspace. Choose it from `../../../workspaces/README.md`.

## Operating Rule

If setup has not been run, keep working.

- During `save`, ask for the reference, why it matters, slug, and tags.
- During `extract`, inspect the saved reference and acquired artifacts.
- During `curate`, ask for human approval before writing to the knowledge layer.

Default tags are optional conveniences. They are not prerequisites.
