# Swipe Tags

Suggested tags for organizing saved references. Extend anytime.

These are conveniences, not required setup.

## Common tags

| Tag | Use for |
|-----|---------|
| inspiration | General swipe file material |
| competitor | Competitor marketing |
| own-asset | Existing material from the user's brand or project |
| hook | Opening lines, claims, or framing |
| layout | Visual structure, page composition, or section order |
| offer | Pricing, packaging, CTA, or promotion patterns |
| hook-emotion | Text hook that names a frustration or loss |
| hook-curiosity | Text hook that teases a payoff |
| hook-secret | Text hook that signals withheld inside information |
| visual-scroll-stopper | Opening visual that interrupts the scroll on wow factor |
| visual-head-scratcher | Opening visual that makes the viewer ask why |
| animation-style | An art or animation style to build as a look in `../../../workspaces/programmatic-animation/` |
| style-[look-slug] | Groups every reference for one look, for example `style-ink-doodle`. Always paired with `animation-style`. |

Hook tags use the same vocabulary as `../stages/02-extract/references/extraction-fields.md`.

## Tag rules

- Lowercase, hyphenated (e.g. `competitor-ad`, `own-asset`)
- One reference can have multiple tags
- Add new tags during save or curate if nothing fits.
- If Business Memory has approved project tag preferences, use them as suggestions.
- Update `knowledge-layer/index.md` tag list when adding new recurring tags

## Fallback

If no tag is obvious, ask the user for one or use `inspiration` for a general reference.
