# Shared Libraries

Read reusable records directly. Use a library's maintenance workflow only when adding, validating, or changing material.

| Library | Owns | Start |
|---|---|---|
| Business Memory | Approved business, brand, offer, SOP, and project context | [Routing](business-memory/CONTEXT.md) |
| Swipes | Saved examples and extracted patterns; Swipe Engine handles save, extract, curate | [Routing](swipes/CONTEXT.md) |
| Media | Reusable asset discovery, sourcing, source/rights records, local paths, and usage history | [Routing](media/CONTEXT.md) |

Production workspaces own job briefs, scripts, selections, edit decisions, approvals, and delivery. They point to these libraries. A reference is not automatically a cleared production asset. Downloading media does not approve catalog promotion.

Large media remains local and ignored. Track its source, rights, location, and reuse record. Check [the media catalog](media/assets/index.md) before sourcing new files.
