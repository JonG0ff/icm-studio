# Search Checklist

- Search by subject, brand, person, product, place, and visual motif.
- Search by source type: Pexels, YouTube, client asset, generated, owned, public archive.
- Search by rights status before recommending reuse.
- Prefer `ready` assets for public delivery.
- Use `internal-reference-only` assets only for study, planning, or sourcing cleared alternatives.
- Record why each recommended asset fits or does not fit.
