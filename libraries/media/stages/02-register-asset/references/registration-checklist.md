# Registration Checklist

- Check for duplicate source URLs, filenames, titles, and obvious subject matches.
- Use a stable lowercase hyphenated `asset_id`.
- Keep raw files out of Git.
- Record the original source URL or source note.
- Record the local path if the file exists locally.
- Use `ready` only when the asset is cleared for the intended reuse.
- Use `internal-reference-only` for YouTube, social, or unclear editorial clips.
- Add at least one fallback for risky or blocked assets.
- Update `used_in` when the asset is reused in a project.
