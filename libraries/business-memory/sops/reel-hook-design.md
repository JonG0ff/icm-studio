# SOP: Reel Hook Design

Standard process for building the first 3 seconds of a short vertical video.

## When To Use

- Any reel, short, or vertical clip that needs an opening.
- Called by `social-reel.md` at the hook step.
- Loaded by the production workspace when writing the brief's Copy Direction.
- Called at script lock before the script is frozen.

## The Dual-Hook Rule

Every reel needs two hooks running at the same time inside the first 3 seconds:

1. A **visual hook**. What the muted viewer sees.
2. A **text hook**. What the muted viewer reads.

One without the other is a fail. Most weak reels have a text hook over a static or generic opening frame.

## Visual Hook Types

| Type | What it does | Examples |
|------|--------------|----------|
| Scroll stopper | High wow-factor or satisfying visual that interrupts the scroll | Crisp product reveal, striking lighting, a satisfying pour or motion |
| Head scratcher | Makes the viewer ask why that is happening, so they need the payoff | An object treated in an unexpected way, a broken expectation, a mess |

## Text Hook Types

| Type | What it does | Examples |
|------|--------------|----------|
| Emotion-striking | Names a real frustration or loss the viewer feels | "Your best hours are gone by 2 PM" |
| Curiosity-building | Teases a payoff without giving it away | "Nobody told you why the crash happens" |
| Withheld-secret | Signals inside information the viewer is not supposed to have | "Do not show this to anyone still on their third coffee" |

Negative-valence hooks usually outperform positive ones. Naming a problem beats promising a benefit.

That is a permission to be honest about a real pain, not a permission to manufacture outrage. See Not Adopted.

## Inputs Required

1. Brand slug.
2. The one key message the reel must land.
3. The audience.
4. Optional visual references from the swipe-engine knowledge layer.

## Process

1. Load the selected brand voice rules.
2. Draft three hook pairs. Each pair is one visual hook plus one text hook.
3. Name the type of each hook using the tables above.
4. For each pair, write the payoff it promises in one line.
5. Pick one pair.
6. Mark where in the beat map the payoff is delivered.
7. Pass the chosen pair, both type names, and the payoff location to the calling workspace.

Do not skip to one option. Three pairs is the minimum, because the first hook is usually the most obvious one.

When the run is a split test, do not pick one. All three pairs become hook packages in a screening cell, and the audience picks. See `reel-split-test.md`.

## Quality Gate

| Check | Pass Condition |
|-------|----------------|
| Visual hook | A muted viewer sees a reason to stop within 3 seconds |
| Text hook | A muted viewer reads a reason to stay within 3 seconds |
| Both present | Neither hook is missing or arriving after 0:03 |
| Type named | Each hook is labeled with a type from the tables above |
| Payoff | The hook's promise is delivered, and the beat is named |
| Voice | No hard-constraint violation from the brand voice file |
| Claims | No medical, disease, guaranteed-performance, or unsupported clinical claim |

## Output Contract

The calling workspace decides the output path.

The SOP output should include:
- three hook pairs considered
- the selected visual hook and its type
- the selected text hook and its type
- the promised payoff and the beat that delivers it
- brand voice file loaded
- any swiped references used

## Not Adopted

The source framework includes tactics this SOP deliberately leaves out:

- **Presenter setup and on-camera authority.** Ring lights, controlled office backgrounds, and a real operator building personal authority on camera. Adopt it only if your brand has an approved presenter format. Studying creators' hands, framing, and movement is still useful as a reference.
- **Manufactured outrage and polarizing bait.** Deliberately provoking a hostile comment section conflicts with brand voice rules and with any claims boundary. Engagement bought this way is not the engagement this system is trying to produce.
