# SOP Library

Standard operating procedures for recurring marketing output types.

## SOP Routing

| Need | Load | Use For |
|------|------|---------|
| Short vertical video | `social-reel.md` | Reels, TikTok, Shorts, short motion clips |
| Edit footage into a short | `footage-short-quality.md` | Approved hook, purposeful graphics, accurate captions, and mandatory full playback QA |
| Build the first 3 seconds | `reel-hook-design.md` | Visual hook plus text hook, hook types, payoff |
| Keep the viewer past the hook | `reel-retention-progression.md` | Attention reset cadence and scene reset methods |
| Test creative instead of guessing | `reel-split-test.md` | Cells, hook packages, rotation, metrics, decision rule |
| Publish variants without looking like spam | `instagram-publishing-safety.md` | Trial reels, interleaving, differentiation, throttle response |

## Rules

- SOPs define process and quality gates.
- An SOP may name the outside source it was adapted from. That source is cited, not authoritative, and is not stored here.
- SOPs do not own output paths. The calling workspace owns its output folder.
- Load brand files only when the SOP asks for voice, offer, CTA, or visual rules.
- Keep SOPs under 200 lines. Split if they grow.
