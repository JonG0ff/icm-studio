# SOP: Social Reel

Standard process for producing a 15 to 60 second vertical social video.

## When To Use

- Platform: Instagram Reels, TikTok, YouTube Shorts, LinkedIn vertical video.
- Goal: awareness, demand creation, or engagement.
- Asset: talking head, screen capture, motion graphic, or narrated short.

## Inputs Required

1. Brand slug.
2. One audience.
3. One key message.
4. Optional offer or CTA.
5. Optional visual reference from the swipe-engine knowledge layer.
6. Optional theme from `../brand-vault/themes/`.

## Process

1. Load the selected brand identity and voice rules.
2. Load `../content-types/short-form-video.md`.
3. Load visual tokens and selected theme if the output includes visual direction.
4. Draft three hook options using `reel-hook-design.md`.
5. Pick one hook and build the beat map.
6. Map attention resets across the beat map using `reel-retention-progression.md`.
7. Keep the reel to one key message.
8. Add CTA only if it does not dilute the point.
9. Route the final spec to the active output workspace.

## Quality Gate

| Check | Pass Condition |
|-------|----------------|
| Hook | Passes the `reel-hook-design.md` quality gate, including both hooks by 0:03 |
| Retention | Passes the `reel-retention-progression.md` reset cadence gate |
| Message | The reel has one point, not a list of points |
| Voice | No hard-constraint violations from the brand voice file |
| CTA | CTA matches the selected brand or project memory |
| Visuals | Aspect ratio and safe zones are named |

## Output Contract

The calling workspace decides the output path.

The SOP output should include:
- hook, with both hook types named
- beat map
- attention reset map
- visual direction
- CTA
- required brand files loaded
- any swiped references used
