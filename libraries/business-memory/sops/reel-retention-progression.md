# SOP: Reel Retention Progression

Standard process for keeping a viewer past the hook.

## When To Use

- Any reel, short, or vertical clip longer than about 8 seconds.
- Called by `social-reel.md` when building the beat map.
- Called at scene planning, before shots are locked.

## The Attention Reset Rule

Change something visible every 2 to 3 seconds.

A frame that holds longer than about 3 seconds without a change is a retention leak. The viewer has already read the text, seen the image, and has nothing new to process.

Any of these count as a reset:

- Camera angle or framing
- Subject or product in frame
- Background or surface
- On-screen text
- A cut, push-in, or clear motion change

Changing the audio alone does not count. The reset must be visible to a muted viewer.

## Reset Methods

| Method | What it is | Use when |
|--------|-----------|----------|
| Aesthetic reset | Move a prop, surface, plant, or backdrop into frame between clips so the background reads as a new place | You are shooting in one location and need visual variety |
| Dynamic angle | Wide to tight, reframe, rotate, or change lens height on the same subject | The subject must stay the same but the shot is going stale |
| Subject swap | Cut to a different object, hand action, or graphic | The beat map moves to a new idea |
| Overlay change | New on-screen text, callout, or graphic element lands | The visual must hold but the point advances |

## Inputs Required

1. The locked or drafted beat map.
2. The selected hook pair from `reel-hook-design.md`.
3. Total target runtime.
4. Optional media references from the swipe-engine knowledge layer.

## Process

1. Lay the beat map against a timeline in seconds.
2. Mark every point where something visible changes.
3. Find every gap longer than 3 seconds.
4. For each gap, pick a reset method from the table and assign it.
5. Mark any hold longer than 3 seconds that is deliberate, and write one line on why it earns the time.
6. Pass the reset map to the scene plan.

A deliberate hold is allowed. An accidental one is not. The difference is whether it is written down.

## Quality Gate

| Check | Pass Condition |
|-------|----------------|
| Reset cadence | No gap over 3 seconds without a change, unless the hold is marked deliberate |
| Method named | Every reset has a method from the table above |
| Muted test | Every reset is visible with sound off |
| Purpose | Each reset carries the point forward, it does not just decorate |
| Runtime | The reset map covers the full runtime, not only the opening |

## Split Tests

In a split test the body is the locked spine, shared by every package in the cell. Build the reset map once, at the spine, and it carries to every package. See `reel-split-test.md`.

## Output Contract

The calling workspace decides the output path.

The SOP output should include:
- the reset map, in seconds
- the method assigned to each reset
- any deliberate hold and its justification
- brand voice file loaded
- any swiped references used

## Not Adopted

The source framework's Phase V pairs this method with post-publish comment-section provocation and with a stance that saturation does not matter. Neither is adopted here. This SOP covers what happens inside the video only.
