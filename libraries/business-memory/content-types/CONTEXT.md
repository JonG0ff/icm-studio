# Content Types

Reusable templates for marketing formats.

## Template Routing

| Need | Load | Use For |
|------|------|---------|
| 15 to 60 second vertical video | `short-form-video.md` | Reels, TikTok, Shorts |
| Still-first PiP reel with a 44-image bank | `still-first-reel.md` | Blank Hook Grid and B-Roll script format |
| A set of variants that test one question | `split-test-cell.md` | Split-test cells, hook packages, read plan |

## Rules

- Content type files define format constants and required sections.
- When a content type carries an affiliate link, check `../offers/CONTEXT.md` for compliance before publishing.
- They do not define brand voice.
- They do not choose output paths.
- Pair a content type with a SOP when producing real work.
