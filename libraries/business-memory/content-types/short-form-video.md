# Content Type: Short-Form Video

Template for a 15 to 60 second vertical video.

## Format Constants

- Aspect ratio: 9:16.
- Resolution: 1080x1920.
- Length: 15 to 60 seconds.
- Safe zones: top 20 percent and bottom 15 percent reserved for platform UI.

## Required Sections

1. **Hook, 0 to 3 seconds:** a visual hook and a text hook together. No logo first. See `../sops/reel-hook-design.md`.
2. **Setup, 3 to 10 seconds:** only the context the viewer needs.
3. **Delivery, 10 to 45 seconds:** one core idea.
4. **CTA, 45 to 60 seconds:** what to do next, only if useful.

Across all sections, change something visible every 2 to 3 seconds. See `../sops/reel-retention-progression.md`.

## Voice Notes

- Load the selected brand's `voice-rules.md`.
- Use short declarative sentences.
- Fragments are allowed.
- No hype words.

## Spec Fields

- title
- brand slug
- audience
- message
- hook
- hook type (visual and text)
- beat map
- progression plan
- visual direction
- CTA
- source references
