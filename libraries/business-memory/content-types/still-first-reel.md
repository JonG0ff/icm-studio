# Still-First Reel Format

Blank starter for the still-bank method. The job brief sets platform, runtime,
voice, palette, PiP treatment, and delivery. This format does not select a brand.

## Constants

- 40 distinct body stills and four distinct hook panels. No repeated images.
- Hook order: top left, top right, bottom left, bottom right.
- Body slots: 01 through 40 in script order. Hook slots become 41 through 44.
- A product screen or promo beat is outside the still bank.
- Plan readable holds from the narration. Verify every timecode before script lock.
