# Themes

Theme files adapt shared tokens for a specific campaign mood or output surface.

## Theme Routing

| Theme | File | Use For |
|-------|------|---------|
| Default | `default.md` | General marketing outputs unless a campaign-specific theme exists |

## Rules

- Themes may reference tokens from `../tokens.md`.
- Themes do not redefine brand identity or voice.
- Add one theme file per campaign or recurring visual mode.
- If a theme conflicts with tokens, update tokens first or mark the theme as experimental.
