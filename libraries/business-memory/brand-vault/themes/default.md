# Theme: Default

Default visual direction for marketing outputs.

## Use When

- No campaign-specific theme exists.
- The output needs to feel clear, practical, and direct.

## Visual Direction

- Use high contrast between background and text.
- Keep layouts structured and easy to scan.
- Favor concrete product or process visuals over abstract decoration.
- Use accent color for emphasis, not as the whole palette.

## Token References

- Colors, fonts, radius, and safe zones come from `../tokens.md`.
