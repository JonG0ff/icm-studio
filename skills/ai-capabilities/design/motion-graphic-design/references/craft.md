# Direction And Craft

Adapted from the three MIT methods identified in `../NOTICE.md`. The values below are choices to make for a job, not universal numerical rules.

## Motion Language

| Choice | Decide |
|---|---|
| Intent | What should the viewer understand and feel? |
| Type | Display and supporting styles, sizes, line breaks, reading order |
| Composition | Focal point, negative space, depth, alignment, safe areas |
| Timing | Entrance, emphasis, reading hold, exit, and overall energy |
| Easing | A small family that fits the brand and object weight |
| Transition | How one idea becomes or reveals the next |
| Audio | Speech, score, accents, or intentional silence |

## Compose The Meaning

- Give the principal idea the strongest size, contrast, and motion.
- Let supporting elements establish context or relationships.
- Keep texture quiet enough that it does not compete with the message.
- Preserve useful stillness. Reading text does not need continuous animation.
- Design vertical frames directly. Restack content when adapting aspect ratios.
- Check platform UI clearance using the job's delivery requirements.

## Make Movement Believable

Match acceleration, travel, and duration to the action. A heavy object needs different spacing from a small annotation. Use anticipation, arcs, overlap, or follow-through when they communicate weight or cause and effect.

Stagger when order matters. Reveal a group together when it represents one unit. Use linear movement for a steady rate or another clear intention. Do not replace all motion with the same spring or apply every animation principle to every element.

## Choreograph Across Scenes

Carry a shape, position, label, or relationship into the next beat when it helps the story. Establish the graphic, develop its meaning, then resolve it. Reserve strong transitions for a real change in the idea.

Keep screen-copy timing distinct from speech captions. Do not invent word timing. Let important text settle long enough to read at normal playback speed.

## Diagnose Before Adding Effects

| Symptom | Check first |
|---|---|
| Busy | Competing focal points or too many simultaneous actions |
| Cheap or generic | Weak typography, inconsistent spacing, unrelated presets |
| Floaty | Travel and duration do not imply the intended weight |
| Hard to follow | No visual relationship between beats |
| Hard to read | Poor contrast, crowded layout, short hold, clipping |
| Inconsistent | Comparable elements use unrelated timing or treatments |

Prefer the smallest correction that restores the message. Add effects only when they improve the selected treatment.
